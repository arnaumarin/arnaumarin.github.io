    Plotting And Image Encoding API¶

    Unit Image Encoding¶

    spikeagent.app.tool.si_custom.custom_plot.create_unit_img_df(sortinganalyzer, unit_ids=None, features=UNIT_FEATURES, load_if_exists=True, save_folder=None, **kwargs) ¶

    Creates a DataFrame of base64-encoded images for specified units and features.

    This function can save the DataFrame to a CSV file for caching. The save path is determined by the save_folder argument or derived from the analyzer's folder.

    Parameters:

    Name Type Description Default
    sortinganalyzer SortingAnalyzer

    The analyzer object containing the data.

    		 required
    unit_ids list

    A list of unit IDs to generate images for. If None, all units are used.

    		 None
    features list

    A list of feature plots to generate.

    		 UNIT_FEATURES
    load_if_exists bool

    If True, and a cached CSV exists, it will be loaded instead of regenerating.

    		 True
    save_folder str or Path

    The folder where the 'unit_img.csv' file should be saved. If not provided, it will be inferred from sortinganalyzer.folder.

    		 None
    **kwargs dict

    Additional keyword arguments (not currently used).

    		 {}

    Returns:

    Type Description
    DataFrame

    A DataFrame where the index is unit_id and columns are the requested features. Each cell contains a base64-encoded PNG image string.

    Merge Image Encoding¶

    spikeagent.app.tool.si_custom.custom_plot.create_merge_img_df(sortinganalyzer, unit_groups, features=MERGE_FEATURES, load_if_exists=True, save_folder=None, show_density=True, **kwargs) ¶

    Creates a DataFrame of base64-encoded images for specified unit groups.

    This function can save the DataFrame to a CSV file for caching. The save path is determined by the save_folder argument or derived from the analyzer's folder.

    Parameters:

    Name Type Description Default
    sortinganalyzer SortingAnalyzer

    The analyzer object containing the data.

    		 required
    unit_groups list of lists

    A list of unit ID groups to generate comparison images for.

    		 required
    features list

    A list of feature plots to generate for comparison.

    		 MERGE_FEATURES
    load_if_exists bool

    If True, and a cached CSV exists, it will be loaded instead of regenerating.

    		 True
    save_folder str or Path

    The folder where the 'merge_img.csv' file should be saved. If not provided, it will be inferred from sortinganalyzer.folder.

    		 None
    show_density bool

    Whether to show density plot in PCA clustering. If True, creates dual-panel plot. If False, creates single scatter plot. Default is True.

    		 True
    **kwargs dict

    Additional keyword arguments (not currently used).

    		 {}

    Returns:

    Type Description
    DataFrame

    A DataFrame where the index is group_id and columns are the requested features. Each cell contains a base64-encoded PNG image string.
