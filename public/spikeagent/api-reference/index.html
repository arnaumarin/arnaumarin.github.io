    API Reference¶

    This document provides detailed documentation for SpikeAgent's programmatic API.

    Overview¶

    SpikeAgent provides both a web interface and a Python API. This reference covers the Python API for programmatic usage, allowing you to integrate AI-powered curation and merging into your custom SpikeInterface workflows.

    Installation¶

    This section covers installing SpikeAgent for programmatic API usage in your own Python scripts and Jupyter notebooks.

    Prerequisites¶

    • Python 3.11 or later
    • pip (Python package manager)
    • Git (to clone the repository)

    Installation Steps¶

    1. Clone the repository: 

      git clone https://github.com/SpikeAgent/SpikeAgent.git
cd SpikeAgent

    2. Install in editable mode: 

      pip install -e .

    Verify Installation¶

    # Test the import
from spikeagent.curation.vlm_curation import run_vlm_curation
from spikeagent.app.tool.utils import get_model
print("SpikeAgent installed successfully!")

    Core Curation & Analysis¶

    These functions represent the heart of SpikeAgent's AI logic.

    spikeagent.curation.vlm_curation¶

    run_vlm_curation(model, sorting_analyzer, img_df, ...)¶

    Classifies units as "Good" or "Bad" using a Vision-Language Model.

    Parameters: - model: The VLM model instance (typically from get_model()). Note: gpt-4o is recommended for optimal speed. - sorting_analyzer (SortingAnalyzer): The SpikeInterface analyzer object. - img_df (pd.DataFrame): DataFrame of encoded images generated by create_unit_img_df(). - features (list): Modalities to analyze. Available: "waveform_single", "waveform_multi", "autocorr", "spike_locations", "amplitude_plot". - num_reviewers (int, default=1): Number of independent AI reviews per unit. Use 1 for maximum speed (default), or 3 for robust consensus voting. - with_metrics (bool, default=False): If True, includes quantitative quality metrics in the AI prompt. - metrics_list (list, optional): Specific metrics to include (e.g., ["snr", "isi_violations_ratio"]). See Quality Metrics below. - good_ids / bad_ids (list): Pre-labeled unit IDs for few-shot learning (provides visual examples to the AI). - unit_ids (list, optional): Subset of units to analyze. - num_workers (int, default=50): Number of parallel processes for API calls.

    Returns: - pd.DataFrame: Results containing final classifications, quality scores, and detailed AI reasoning.

    spikeagent.curation.vlm_merge¶

    run_vlm_merge(model, merge_unit_groups, img_df, ...)¶

    Analyzes pairs or groups of units to determine if they should be merged.

    Parameters: - model: The VLM model instance. Both gpt-4.1 and gpt-4o are highly effective for merge analysis. - merge_unit_groups (list): A list of unit groups (e.g., [[1, 5], [10, 12]]) to evaluate for merging. - Note: These are typically generated using spikeinterface.curation.compute_merge_unit_groups. - img_df (pd.DataFrame): DataFrame of encoded images generated by create_merge_img_df(). - features (list): Modalities to analyze. Available: "waveform_single", "waveform_multi", "crosscorrelograms", "spike_locations", "amplitude_plot". - good_merge_groups / bad_merge_groups (list): Example group indices for few-shot calibration. - num_workers (int, default=50): Number of parallel processes.

    Returns: - pd.DataFrame: Results with "merge" or "not merge" decisions and reasoning.

    Plotting & Image Generation¶

    These functions prepare the visual data required for VLM analysis or human review.

    Encoding for VLM¶

    Prerequisite: You must compute the required SpikeInterface extensions before generating images. To ensure compatibility with SpikeAgent's plotting functions, we recommend the following full suite computation:

    extension_params = {
    "random_spikes": {"method": "uniform", "max_spikes_per_unit": 600},
    "waveforms": {"ms_before": 1.0, "ms_after": 2.0},
    "templates": {},
    "template_similarity": {},
    "spike_locations": {},
    "unit_locations": {},
    "isi_histograms": {"window_ms": 30, "bin_ms": 0.5, "method": "auto"},
    "correlograms": {"window_ms": 30, "bin_ms": 0.5, "method": "auto"},
    "spike_amplitudes": {},
    "noise_levels": {},
    "principal_components": {},
    "quality_metrics": {
        "metric_names": [
            "snr", "firing_rate", "isi_violation",
            "presence_ratio", "amplitude_cutoff", "amplitude_median", 'l_ratio', 'nearest_neighbor',
        ]
    }
}

for key, value in extension_params.items():
    extension = analyzer.get_extension(key)
    # Only compute if missing or parameters don't match
    if extension is None or not value.items() <= extension.params.items():
        analyzer.compute(key, **value)

    create_unit_img_df(sortinganalyzer, unit_ids=None, features=None, load_if_exists=True, save_folder=None, **kwargs)¶

    Generates base64-encoded diagnostic images for individual units. The resulting DataFrame is used as input for run_vlm_curation.

    Parameters: - sortinganalyzer (SortingAnalyzer): The SpikeInterface analyzer object containing the data. - unit_ids (list, optional): List of unit IDs to generate images for. If None, processes all units in the analyzer. - features (list, optional): List of feature plots to generate. Default is ["waveform_single", "waveform_multi", "autocorr", "spike_locations", "amplitude_plot"]. - load_if_exists (bool, default=True): If True and a cached CSV exists, loads it instead of regenerating. If False, deletes any existing cache and regenerates all images. If no file exists, always generates new images. - save_folder (str or Path, optional): Directory where unit_img.csv will be saved. If not provided, inferred from sortinganalyzer.folder. - **kwargs: Additional keyword arguments (currently unused).

    Returns: - pd.DataFrame: DataFrame indexed by unit_id, with columns for each feature. Each cell contains a base64-encoded PNG image string.

    Caching Behavior: - Automatically saves to/loads from unit_img.csv in the specified folder - If save_folder is not provided and analyzer has no folder, a warning is issued and images are not cached

    create_merge_img_df(sortinganalyzer, unit_groups, features=None, load_if_exists=True, save_folder=None, show_density=True, **kwargs)¶

    Generates base64-encoded comparison images for unit merge candidates. Used as input for run_vlm_merge.

    Parameters: - sortinganalyzer (SortingAnalyzer): The analyzer object containing the data. - unit_groups (list of lists): List of unit ID groups to evaluate for merging (e.g., [[1, 5], [10, 12]]). Typically generated using spikeinterface.curation.compute_merge_unit_groups. - features (list, optional): List of feature plots to generate for comparison. Default is ["waveform_single", "amplitude_plot", "crosscorrelograms"]. - load_if_exists (bool, default=True): Same behavior as create_unit_img_df. - save_folder (str or Path, optional): Directory where merge_img.csv will be saved. - show_density (bool, default=True): Reserved for future use (currently unused). - **kwargs: Additional keyword arguments (currently unused).

    Returns: - pd.DataFrame: DataFrame indexed by group_id, with columns for each feature. Each cell contains a base64-encoded JPEG image string.

    Caching Behavior: - Automatically saves to/loads from merge_img.csv - Each unit in a group is color-coded for visual comparison

    Diagnostic Visualization¶

    plot_units_with_features(sortinganalyzer, unit_ids=None, features=None, save=False, **kwargs)¶

    Generates a multi-panel grid plot for each unit, displaying multiple diagnostic features side-by-side for human inspection.

    Parameters: - sortinganalyzer (SortingAnalyzer): The analyzer object. - unit_ids (list, optional): List of unit IDs to plot. If None, plots the first 10 units. - features (list, optional): List of features to display. Default is ["waveform_single", "waveform_multi", "autocorr", "spike_locations", "amplitude_plot"]. - save (bool, default=False): If True, saves plots as JPEG files to [analyzer_folder]/feature_plot/. - **kwargs: Additional keyword arguments (currently unused).

    Returns: - None (displays matplotlib figures)

    Notes: - Creates horizontal strip plots with dynamically sized panels - Each unit gets its own figure with all requested features

    plot_units_with_features_df(sortinganalyzer, encoded_img_df, features=None, unit_ids=None, save=False, resize_height=None, save_dpi=300)¶

    Displays the encoded images from a VLM DataFrame. Useful for visualizing exactly what images were sent to the AI during curation.

    Parameters: - sortinganalyzer (SortingAnalyzer): The analyzer object. - encoded_img_df (pd.DataFrame): DataFrame of base64-encoded images (output from create_unit_img_df). - features (list, optional): Features to display. Default is UNIT_FEATURES. - unit_ids (list, optional): Subset of units to plot. If None, plots all units in the DataFrame. - save (bool, default=False): If True, saves PNG files to [analyzer_folder]/feature_plot/. - resize_height (int, optional): Height in pixels to resize images to. If None, uses native resolution. - save_dpi (int, default=300): DPI for saved images.

    Returns: - None (displays matplotlib figures and optionally saves to disk)

    plot_spike_images_with_result(results_df, encoded_img_df, feature="waveform_single")¶

    Plots curation results alongside unit images to visually verify AI classification. Separates units into "Good" and "Bad" grids.

    Parameters: - results_df (pd.DataFrame): Results from run_vlm_curation containing final_classification and average_score columns. - encoded_img_df (pd.DataFrame): DataFrame of base64-encoded images (from create_unit_img_df). - feature (str, default="waveform_single"): Which feature image to display for each unit.

    Returns: - None (displays two matplotlib figures: one for "Good" units, one for "Bad" units)

    Notes: - Displays up to 5 units per row in a grid layout - Shows unit ID and quality score as subplot titles - Automatically handles dynamic grid sizing

    plot_merge_results(results_df, encoded_img_df)¶

    Plots merge analysis results showing the comparison images and the AI's "merge" or "not merge" decision for each unit group.

    Parameters: - results_df (pd.DataFrame): Results from run_vlm_merge containing merge_type and merge_units columns. - encoded_img_df (pd.DataFrame): DataFrame of base64-encoded merge images (from create_merge_img_df).

    Returns: - None (displays matplotlib figures, one per merge group)

    Notes: - Concatenates all features horizontally for each group - Shows group ID, unit IDs, and merge decision in the title - Each group gets its own figure

    Utilities¶

    get_model(model_name, temperature=0)¶

    Initializes a chat model interface for use with curation functions.

    Supported model_name strings: - OpenAI: "gpt-4o", "gpt-4.1", "gpt-5.2", "gpt-5-mini" - Anthropic: "claude_4_sonnet", "claude_4_opus", "claude_3_7_sonnet", "claude_4_5_sonnet", "claude_4_5_haiku", "claude_4_5_opus" - Gemini: "gemini-3-pro-preview", "gemini-3-flash-preview", "gemini-2.5-pro", "gemini-2.5-flash"

    Example Usage¶

    1. Automated Unit Curation¶

    import spikeinterface.full as si
from spikeagent.app.tool.utils import get_model
from spikeagent.app.tool.si_custom import create_unit_img_df
from spikeagent.curation.vlm_curation import run_vlm_curation

# 1. Load data
analyzer = si.load_sorting_analyzer("my_analyzer.zarr")

# 2. Compute required extensions (using specific parameters for VLM)
extension_params = {
    "random_spikes": {"method": "uniform", "max_spikes_per_unit": 600},
    "waveforms": {"ms_before": 1.0, "ms_after": 2.0},
    "templates": {},
    "template_similarity": {},
    "spike_locations": {},
    "unit_locations": {},
    "isi_histograms": {"window_ms": 30, "bin_ms": 0.5, "method": "auto"},
    "correlograms": {"window_ms": 30, "bin_ms": 0.5, "method": "auto"},
    "spike_amplitudes": {},
    "noise_levels": {},
    "principal_components": {},
    "quality_metrics": {
        "metric_names": [
            "snr", "firing_rate", "isi_violation",
            "presence_ratio", "amplitude_cutoff", "amplitude_median", 'l_ratio', 'nearest_neighbor',
        ]
    }
}
for key, value in extension_params.items():
    extension = analyzer.get_extension(key)
    if extension is None or not value.items() <= extension.params.items():
        analyzer.compute(key, **value)

# 3. Encode images (Modality: Waveform + Autocorr + Locations)
features = ["waveform_single", "autocorr", "spike_locations"]
img_df = create_unit_img_df(analyzer, features=features, load_if_exists=True)

# 4. Run AI Curation (Fast mode with 1 reviewer)
model = get_model("gpt-4o")
results = run_vlm_curation(
    model=model,
    sorting_analyzer=analyzer,
    img_df=img_df,
    features=features,
    num_reviewers=1,
    with_metrics=True
)

# 5. Filter for good units
good_unit_ids = results[results['final_classification'] == 'Good'].index.tolist()
print(f"Found {len(good_unit_ids)} high-quality units.")

    Reference Lists¶

    Modality Features¶

    Feature Name Description Used In
    waveform_single Single-channel average waveform plot Curation & Merge
    waveform_multi Multi-channel template plot Curation & Merge
    autocorr Autocorrelogram of spike times Curation
    crosscorrelograms Cross-correlogram between units Merge
    spike_locations Spatial spike location scatter plot Curation & Merge
    amplitude_plot Amplitude distribution over time Curation & Merge

    Quality Metrics¶

    Available for use in run_vlm_curation(metrics_list=...): - snr: Signal-to-Noise Ratio. - isi_violations_ratio: Inter-Spike Interval violation rate (contamination rate). - presence_ratio: Fraction of recording where spikes are present. - amplitude_cutoff: Estimate of missed spikes due to thresholding. - l_ratio: Cluster isolation based on Mahalanobis distance. - nn_hit_rate: Nearest-neighbor true positive rate. - nn_miss_rate: Nearest-neighbor false negative rate.
